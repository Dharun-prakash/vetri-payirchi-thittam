# FitBuddy - AI Fitness Plan Generator

FitBuddy is an AI-powered fitness planning web application.

It uses:

- FastAPI
- Jinja2
- SQLite
- SQLAlchemy
- Google Gemini
- HTML
- CSS

## Features

1. Personalized 7-day workout plan
2. Nutrition/recovery tip
3. Feedback-based plan updates
4. SQLite database
5. Admin dashboard
6. REST API
7. Swagger API documentation
8. Demo mode without an API key
